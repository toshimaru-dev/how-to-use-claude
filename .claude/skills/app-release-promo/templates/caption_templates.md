# 投稿文トンマナ別テンプレート

このファイルは投稿文を書く際の「型」を示すガイド。プレースホルダー（`{{...}}`）はそのまま埋め込み用のヒントであり、実際に生成する投稿文はこの型を参考にしながら自然な日本語で書き起こすこと。テンプレート文をそのままコピペで穴埋めするのではなく、トンマナ・訴求ポイントに応じて言い回しを都度作る。

---

## トンマナ: カジュアル（デフォルト）

- 絵文字を要所に使う（多用しすぎない。1文につき0〜2個目安）
- 「〜だよ」「〜です！」など話し言葉寄りの語尾
- 訴求ポイントは箇条書き寄りのテンポで列挙してもよい

**Instagram例（型）:**
```
🎉 {{リリース種別}}のお知らせ 🎉

「{{アプリ名}}」{{一言コンセプト}}

✅ {{訴求ポイント1}}
✅ {{訴求ポイント2}}
✅ {{訴求ポイント3}}

{{ストアURLがあれば一言（プロフィールのリンクから、等）}}

{{ハッシュタグ}}
```

**Threads例（型・500字以内）:**
```
「{{アプリ名}}」{{リリース種別}}しました🎉
{{一言コンセプト}}

{{訴求ポイントを1〜2個、会話的な一文で}}

{{ハッシュタグ（1〜3個程度）}}
```

---

## トンマナ: 落ち着いた（フォーマル寄り）

- 絵文字は使わないか、使っても1個程度に抑える
- 「〜しました」「〜です」の丁寧語で統一
- 訴求ポイントは短い説明文として書く（箇条書きにする場合も装飾記号は最小限）

**Instagram例（型）:**
```
{{アプリ名}}を{{リリース種別}}しました。

{{一言コンセプト}}

主な特徴は次のとおりです。
・{{訴求ポイント1}}
・{{訴求ポイント2}}
・{{訴求ポイント3}}

{{ストアURLがあれば一文で案内}}

{{ハッシュタグ}}
```

**Threads例（型・500字以内）:**
```
{{アプリ名}}を{{リリース種別}}しました。
{{一言コンセプト}}

{{訴求ポイントを1つだけ端的に}}

{{ハッシュタグ}}
```

---

## トンマナ: エンジニア向け

- 技術的な背景・実装意図に軽く触れてよい
- 過度な煽り文句を避け、事実ベースで簡潔に
- ハッシュタグは技術系タグ（#個人開発 #iOSアプリ 等）を優先

**Instagram例（型）:**
```
{{アプリ名}}を{{リリース種別}}しました。

{{一言コンセプト}}

{{訴求ポイントを開発背景と絡めて1〜2文で}}

技術的なポイント:
・{{訴求ポイント1}}
・{{訴求ポイント2}}

{{ストアURL案内}}

{{ハッシュタグ}}
```

**Threads例（型・500字以内）:**
```
{{アプリ名}}を{{リリース種別}}。
{{一言コンセプトを技術寄りの一文で}}

{{訴求ポイントを1つ、開発視点で}}

{{ハッシュタグ}}
```

## プラットフォームごとの注意点

### Instagram
- キャプション上限は長め（最大2,200字程度）だが、実際に読まれるのは冒頭2〜3行程度。訴求の核は最初に置く。
- 改行を多めに使い、視覚的に読みやすくする。
- ハッシュタグは本文末尾にまとめる（本文中に混ぜない）。目安5〜15個。ユーザーが個数目安を指定した場合はそれに従う。

### Threads
- 500字制限。冗長な前置きを避け、テンポよく。
- ハッシュタグは控えめ（0〜3個程度）。
- 会話的・素の言葉遣いのほうが伸びやすい傾向。「〜だった」「〜してみた」等の一人称の実感がこもった文体と相性が良い。

---

## 出力形式

各投稿文は2〜3案を提示し、以下のように保存する。

```markdown
# {{アプリ名}} - Instagram投稿文案

## 案1（{{トンマナ}}）
{{本文}}

## 案2
{{本文}}
```
