0 このガイドについて

このリポジトリは Claude Code（Anthropic の AI 開発支援ツール）と Codex CLI（OpenAI の CLI エージェント）を組み合わせた スマホ・ウェブアプリ開発の Windows 向けスターターキット です。

セットアップは 3 ステップ。Claude Code を起動してから先は、 スキルが対話形式で必要なツールのインストールと設定を案内します。 コマンドを一つひとつ調べる必要はありません。

✅

管理者権限が必要な操作のみ PowerShell（管理者） で実行するよう案内されます。 スタートメニューで「PowerShell」と検索し、右クリック →「管理者として実行」で開いてください。

2 Step 1　Node.js と Claude Code をインストールする

Claude Code を動かすには Node.js が必要です。 これだけ手動でインストールします。残りのツールはスキルが案内します。

Node.js をインストールする

PowerShell（管理者）で以下を実行します。

PowerShell（管理者） 
winget install -e --id OpenJS.NodeJS.LTS
⚠️

インストール後は PowerShell を閉じて開き直してください。新しくインストールしたコマンドは再起動しないと認識されません。

ℹ️

winget が使えない場合は nodejs.org からインストーラーをダウンロードしてください。

Claude Code をインストールする

PowerShell（管理者）で以下を実行します。

PowerShell（管理者） 
npm install -g @anthropic-ai/claude-code
Windows PowerShell（管理者）
PS C:\Users\user> npm install -g @anthropic-ai/claude-code added 142 packages in 18s PS C:\Users\user> claude --version 1.x.x PS C:\Users\user>

setup スキルが対応する内容

対応内容手動 / 自動

6 全体の開発フロー

セットアップ完了後は、Claude Code に話しかけるだけで開発が進みます。

Phase 1

要件定義

機能の目的・受け入れ基準を整理し docs/dev-workflow/<機能名>/requirements.md に保存。

Claude Code
Phase 2

設計

アーキテクチャ・API 設計・Codex への実装指示を含む設計書を作成。

Claude Code
Phase 3

実装（Codex に委任）

設計書の実装指示を Codex に渡してコードを書かせる。差し戻しも同じスレッドで継続。

Codex
Phase 4

評価

受け入れ基準の突き合わせ・コードレビュー・セキュリティチェック。不合格なら Phase 3 へ差し戻し。

Claude Code
Phase 5

リリース準備

CHANGELOG・PR 説明の下書き。SNS 告知素材が必要なら app-release-promo スキルへ委譲。

Claude Code

7 スキル一覧

Claude Code に話しかけるだけでスキルが自動起動します。

⚙️

setup

トリガー：「セットアップして」「環境構築して」「ツールをインストールして」

  • チェックスクリプトで現状を確認し、不足ツールのみ補完
  • Git・GitHub CLI・VS Code は winget コマンドを提示して案内
  • Codex CLI のインストールと MCP 登録は自動実行
  • すべて完了したら再確認スクリプトで OK を確認
🔍

setup-check

トリガー：「セットアップ確認して」「環境チェック」「何が足りないか教えて」

  • Node.js・Git・GitHub CLI・VS Code・Claude Code・Codex CLI を一括確認
  • Codex ログイン状態・MCP codex 登録状況もチェック
  • ❌ がある場合は setup スキルへの誘導を提案
🔄

dev-workflow

トリガー：「〇〇機能を実装したい」「要件定義して」「この機能を作って」

  • 要件定義→設計→Codex 委任→評価→リリース準備を一気通貫で管理
  • 各フェーズで成果物を docs/dev-workflow/ に自動保存
  • 評価で不合格なら自動的に差し戻しループを実行
  • セキュリティレビュー（OWASP Top 10 視点）を標準搭載
📢

app-release-promo

トリガー：「リリース告知素材作って」「SNS 投稿文作って」

  • Instagram / Threads 向け投稿文を複数案生成
  • アプリアイコン＋キャッチコピーの告知バナー画像（PNG）を生成
  • Codex CLI 経由で AI コンセプト画像を生成（オプション）
  • 生成物は release-assets/<アプリ名>/<日付>/ に保存

9 Tips & ベストプラクティス

場面ポイント
要件定義受け入れ基準は「〇〇した時に△△になる」の形で書くほど、評価フェーズがスムーズになる
差し戻しCodex への修正指示は必ず同じ threadId で送る。新しいセッションを立てると文脈が失われる
ループが収束しない評価→差し戻しが 3 回を超えたら設計書の粒度を疑う。「設計を見直して」と Claude Code に伝える
CLAUDE.md の活用触ってほしくないファイルや使ってはいけないパッケージがあれば CLAUDE.md に明記する
VS Code との併用Claude Code のターミナルと VS Code を並べておくとコードの確認・手動編集がしやすい

10 トラブルシューティング

症状対処
winget が認識されないMicrosoft Store で「アプリ インストーラー」を更新するか Windows Update を実行
node / claude が認識されないインストール後に PowerShell を開き直していない。閉じて再起動してから再確認
mcp__codex__codex が見当たらないClaude Code を再起動する。それでも出ない場合は「セットアップして」と話しかける
codex: command not found「セットアップして」と話しかけると setup スキルが自動インストールを実行
Codex ログインで権限エラーPowerShell（管理者）で icacls "$env:USERPROFILE\.codex" /grant "$env:USERNAME:(OI)(CI)F"
環境が壊れた・よくわからなくなった「セットアップ確認して」で現状把握 → 問題箇所を「セットアップして」で再設定
Codex が指示と違う実装をした新しいセッションを立てず、mcp__codex__codex-reply で同じ threadId に修正指示を送る
